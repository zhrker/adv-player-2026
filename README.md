# SMB 播放器 2（共享管理 + 文件浏览版）

第二版在第一版基础上增加：

- **添加并保存多个 Windows 共享目录**，账号密码加密保存在手机本地，下次一键连接
- **逐级浏览共享文件夹**，不用手输完整路径
- **排序**：按名称 / 按日期 / 按大小
- **缩略图**：图片文件显示实际缩略图；视频文件暂时显示播放图标（视频缩略图在后续版本做）
- 播放仍使用 VLC 内核，支持 RM/RMVB、MPEG-1/2、MKV、MP4 等

播放手势（隐藏进度条、滑动调亮度音量快进）和投屏等功能放在第三批。

---

## 一、上传到 GitHub 仓库

你的仓库：`https://github.com/zhrker/adv-player-2026`

1. 解压 `adv-player-v2.zip`，得到 `adv-player-v2` 文件夹。
2. 打开仓库网页，用 **Upload files** 把 `adv-player-v2` 文件夹里的**全部文件和子文件夹**上传覆盖到仓库根目录。
3. 确保 `.github/workflows/build.yml` 存在（隐藏文件夹，拖不进去就用 Create new file 手动建）。
4. 点 **Commit changes**。

> 注意：第二版的文件路径和第一版基本一致，直接覆盖同名文件即可。新增了 `file_row.xml` 和 `dialog_add_share.xml`。

## 二、下载 APK

1. 点仓库上方 **Actions**。
2. 等构建完成（绿色勾）。
3. 下载 Artifacts 里的 `smb-player-v2-debug`，解压得到 `app-debug.apk`。

## 三、使用

1. 安装到手机，APP 名字是 **SMB 播放器 2**。
2. 点 **+ 添加共享目录**，填写：
   - 显示名称：随便起，比如"客厅电脑电影"
   - 主机 IP：`192.168.1.10`
   - 共享名：`视频`
   - 用户名 / 密码：Windows 共享账号（匿名留空）
   - 域名：通常留空
3. 保存后，点列表里的共享名即可进入目录浏览。
4. 用右上角 Spinner 切换排序方式；点文件夹进入，点视频开始播放。
5. 点 **共享** 返回共享列表，点 **上一级** 返回上层目录，播放时点 **返回文件** 回到目录。

## 四、已知限制

- 视频文件暂时只显示通用图标，不抽取视频缩略图（后续版本加）
- 播放手势、倍速快捷键、断点续播、后台播放、投屏在第三批做
- 如果 Windows 共享开启了需要域账号或特殊安全策略，可能要调整认证配置；把报错告诉我即可
